# ÉLASTIQUE

Jeu à deux : vous êtes attachés par un élastique et la lave monte. Coopérez pour grimper, trahissez pour gagner.

## Jouer
- **Directement dans le navigateur :** ouvrez le lien GitHub Pages du dépôt.
- **Ou en local :** téléchargez `index.html` et ouvrez-le dans Chrome, Edge ou Firefox.

## En ligne
1. Un joueur appuie sur **2** et envoie le code affiché.
2. L'autre appuie sur **3** et tape le code.

## Touches
| | Joueur 1 | Joueur 2 |
|---|---|---|
| Bouger / sauter | Z Q S D | Flèches |
| S'agripper (au sol) | S | ↓ |
| Tirer l'autre | E | Entrée |
| Se ramener vers l'autre | R | Shift droit |
| Utiliser le pouvoir | F | Ctrl droit ou ! |

En ligne, chacun joue sur son PC avec ZQSD ou les flèches.
